# Express Portfolio Website

## Project Description
A personal portfolio website created for INFR3120 using Node.js, Express.js and EJS. The website includes Home, About Me, Projects and Contact Me pages.

## Technologies Used
- Node.js and Express.js
- EJS
- Bootstrap
- Font Awesome
- HTML, CSS and JavaScript
